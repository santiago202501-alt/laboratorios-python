# Gestor de Inventario Persistente (Laboratorio 4)

Aplicación de consola en Python orientada a objetos con soporte de persistencia en archivos JSON y exportación de reportes en formato CSV.

## Estructura del Proyecto
gestor_inventario/
├── main.py
├── producto.py
├── inventario.py
├── almacenamiento.py
├── reportes.py
├── datos/
│   └── productos.json
├── reportes/
│   └── inventario.csv
└── README.md
