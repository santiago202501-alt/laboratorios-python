# Laboratorio 01 — Primeros pasos con Python

## Descripción del Proyecto
Este repositorio contiene el desarrollo del **Laboratorio 01** del programa de formación en desarrollo de software de SENA. El objetivo principal es la aplicación de los conceptos iniciales de programación en Python: configuración del entorno, ejecución de archivos `.py`, declaración de variables, manejo de tipos de datos (`int`, `float`, `str`), operadores aritméticos, conversiones de tipos y captura de información mediante la función `input()`.

## Contenido de la carpeta `laboratorio-01/`
- `cotizador_compra.py`: Aplicación de consola que solicita los datos de un cliente, producto, precio unitario, cantidad, descuentos e impuestos, calculando de forma organizada el subtotal, valor del descuento, base imponible, impuestos, costo de envío y el total final de la compra.
