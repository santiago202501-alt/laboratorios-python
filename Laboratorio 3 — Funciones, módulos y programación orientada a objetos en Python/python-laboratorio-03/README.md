# Laboratorio 03 — Gestor de Inventario Orientado a Objetos (POO)

## Descripción
Aplicación de consola modular desarrollada en Python que permite administrar un inventario de productos aplicando los principios de la Programación Orientada a Objetos (POO), encapsulamiento, validación estricta de datos y manejo de excepciones.

## Estructura de Archivos
gestor_inventario/
├── main.py
├── producto.py
├── inventario.py

## Instrucciones de Ejecución
Asegúrate de tener Python instalado y ejecuta el programa principal desde la terminal:
```bash
python main.py
