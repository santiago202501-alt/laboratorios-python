# Laboratorio 02 — Decisiones, ciclos y colecciones en Python

## Descripción del Proyecto
Este repositorio contiene el desarrollo del **Laboratorio 02** del programa de formación en desarrollo de software de SENA (Ficha 3388087). El objetivo principal es la aplicación de estructuras de control (`if`, `elif`, `else`, ciclos `while` y `for`), operadores lógicos y colecciones de Python (listas, tuplas, diccionarios y conjuntos) para la gestión de información en memoria.

## Contenido de la carpeta `laboratorio-02/`
- `gestor_inventario.py`: Aplicación interactiva de consola que permite registrar, listar, buscar, actualizar y eliminar productos representados como diccionarios almacenados en una lista. Incluye validación estricta de códigos duplicados, categorías permitidas (mediante tuplas), precios positivos y existencias no negativas, además de consultas de productos sin stock y resúmenes financieros utilizando conjuntos (*sets*) y comprensiones de colecciones.
